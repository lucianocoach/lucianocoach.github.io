KAPON - site para GitHub Pages
=============================

O que tem nesta pasta
---------------------
index.html   -> o site inteiro (HTML, CSS e JavaScript em um arquivo so)
.nojekyll    -> arquivo vazio que impede o GitHub de processar o site com Jekyll
LEIA-ME.txt  -> este guia

Como publicar (5 minutos)
-------------------------
1. Crie um repositorio PUBLICO no GitHub. Ex.: kapon-site
2. Envie os arquivos index.html e .nojekyll para a RAIZ do repositorio
   (pelo site: botao "Add file" -> "Upload files" -> arraste os dois -> Commit).
   Atencao: o .nojekyll comeca com ponto, ele pode ficar oculto no seu computador.
3. No repositorio: Settings -> Pages
   - Source: "Deploy from a branch"
   - Branch: main  /  pasta: / (root)
   - Save
4. Espere de 1 a 2 minutos e acesse:
   https://SEU-USUARIO.github.io/kapon-site/
5. Quando o site abrir, o GitHub mostra o link tambem em Settings -> Pages.

Dominio proprio (kapon.com.br)
-----------------------------
Em Settings -> Pages -> Custom domain, digite o dominio (ex.: www.kapon.com.br).
O GitHub mostra os registros de DNS que devem ser criados no seu provedor
(um CNAME para www apontando para SEU-USUARIO.github.io e/ou registros A para
o dominio sem www). Marque "Enforce HTTPS" depois que o certificado for emitido.

Observacoes
-----------
- As 3 fotos do site estao hospedadas em media.base44.com. Para nao depender
  desse servico, baixe as imagens, coloque na pasta do repositorio (ex.: /img)
  e troque os enderecos dentro do index.html.
- Para trocar textos, edite o proprio index.html.
- Se quiser um site com varias paginas (privacidade, termos), crie os arquivos
  .html na raiz e linke normalmente.
